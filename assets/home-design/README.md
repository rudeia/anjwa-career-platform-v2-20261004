# 홈 디자인 리소스

- 기준: 사용자가 첨부한 codex-clipboard-f785d5a3-24c1-4619-b662-5a328cec848a.png.
- home-glass-background.webp: built-in image_gen 편집으로 원본의 UI를 제거하고 아이보리 배경·청색/민트/금빛 곡면·조명을 보존한 배경. 출력 PNG를 크기 변경 없이 WebP로 인코딩.
- 편집 프롬프트: “Extract the background of this exact approved web design. Preserve the exact blue/mint translucent glass sculpture, its silhouette, lighting, highlights, thin gold edge, position and scale on the right, and original warm ivory background. Remove all UI foreground content and fill removed areas with matching ivory background. No newly designed sculpture, no re-positioning, no lettering.”
- home-reference-details.webp: 사용자 첨부 시안을 WebP로 인코딩. CSS 배경 위치로 사진과 작은 그림 영역만 표시. 실제 학교 사진으로 소개하지 않는 장식 이미지.
- home-heading-serif.woff2: Google Fonts 공식 Noto Serif KR, weight600, 제목에 쓰이는 글자만 포함. 라이선스 NotoSerifKR-OFL.txt(OFL1.1), 빌드에 함께 포함.
- 원본 폰트: https://github.com/google/fonts/tree/main/ofl/notoserifkr

- home-title-serif.woff2: 정보 중심 새 제목 글자에 대해 Google Fonts CSS API에서 받은 Noto Serif KR weight600 서브셋. 기존 OFL 라이선스 적용.
